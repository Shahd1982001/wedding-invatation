# دعوة زفاف ملكية تفاعلية | Luxury Wedding Invitation Template

قالب دعوة زفاف تفاعلي فاخر مصمم كـ **Template جاهز للبيع والاستخدام المتكرر** بأحدث تقنيات الويب الحديثة (HTML5, Modern CSS3, Vanilla JavaScript)، يجمع بين محاكاة فتح الزرف الملكي، والفيزياء المرنة (Spring Physics)، والموسيقى الأوركسترالية، والتأثيرات الزجاجية ثلاثية الأبعاد.

---

## 👰🤵 كيف تستخدمين هذا القالب لزبونة جديدة خطوة بخطوة (Use as Template)

لإنشاء دعوة جديدة تماماً لكل عروس برابط دائم مستقل دون التأثير على العرائس السابقات:

### 1. إنشاء المستودع الجديد:
1. في أعلى هذا المستودع، اضغطي على الزر الأخضر **`Use this template`** ⬅️ **`Create a new repository`**.
2. اكتبي اسم مستودع جديد خاص بالعروسين (مثال: `wedding-sara-ahmed`).
3. اختاري `Public` واضغطي **`Create repository from template`**.

### 2. تعديل بيانات العروسين (خلال دقيقة واحدة فقط):
- **في ملف `index.html`**:
  - ابحثي عن الأسماء وغيّريها لاسم العروسين الجديدين (مثال: `سارة & أحمد`).
  - عدّلي اسم الصالة وموعد الحفل ورابط لوكيشن قوقل ماب.
- **في ملف `js/main.js`**:
  - عدّلي تاريخ العد التنازلي في سطر:
    ```javascript
    const targetDate = new Date('2027-07-26T18:00:00').getTime();
    ```
- **في مجلد `assets/invitation_cards/`**:
  - استبدلي صورتي البولارويد بصور العروسين الجدد (مع الاحتفاظ بنفس الأسماء `polaroid_1.png` و `polaroid_2.png`).

### 3. النشر والحصول على الرابط الدائم للعروس:
- **عبر Vercel**:
  1. افتحي حسابكِ في [Vercel](https://vercel.com) واضغطي **Add New...** ⬅️ **Project**.
  2. اختاري المستودع الجديد (`wedding-sara-ahmed`).
  3. تأكدي أن **Framework Preset** على وضع **Other**، ثم اضغطي **Deploy**.
  4. ستحصلين على رابط دائم خاص بها، مثل: `https://wedding-sara-ahmed.vercel.app`.
- **أو عبر GitHub Pages**:
  - من إعدادات المستودع `Settings` > `Pages` > اختاري فرع `main` واضغطي `Save`.

## المميزات الرئيسية للقالب (Key Features)

- **محاكاة فتح الزرف الملكي (3D Envelope Pop-out Experience)**:
  - ختم شمعي ذهبي نافر بدوران مستمر ومونوغرام العروسين.
  - تفاعل كسر الختم وتوهجه الذهبي مع انبثاق بطاقات الدعوة وصور البولارويد بجاذبية فيزيائية مرنة (Spring Physics).
  - ملصق البجعة الملكية وشارة حفظ التاريخ (Save our Date).
- **المعزوفة الموسيقية (Orchestral Soundtrack)**:
  - عزف أوركسترالي متناغم (Indila - Love Story Orchestral Outro).
  - تشغيل ذكي فوري مع زر للتحكم بالصوت (كتم / تشغيل) بحفظ تلقائي لاختيار المستخدم.
- **خلفية ثابتة وتأثيرات زجاجية راقية (Fixed Royal Canvas & Glassmorphism)**:
  - خلفية قاعة أفراح ملكية وأقواس كلاسيكية ثابتة تماماً أثناء التمرير.
  - تساقط بتلات الورد المتطايرة مع استجابة لحركة السكرول.
  - بطاقات زجاجية فاخرة بتأثير تفاعلي ثلاثي الأبعاد (3D Mouse / Touch Tilt).
- **أقسام الدعوة**:
  - ترحيب ملكي وتفاصيل العروسين.
  - جدول موعد ومكان الحفل الملكي مع رابط الخريطة.
  - عداد تنازلي رقمي حي حتى موعد الزفاف.
  - لوحة إلهام ألوان الحضور (Wedding Color Palette) بأسلوب راقٍ وأنيق.
  - ملاحظات الحفل وأيقونات راقية بدون رسوم كرتونية.
